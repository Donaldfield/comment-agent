解决电商评论分析问题
独立开发一款基于大模型与LangGraph的电商评价智能分析系统，面向电商海量非结构化用户评论数据，实现评价采集降噪、细粒度情感分析、痛点挖掘、向量知识库归因、舆情预警及可视化报表生成全流程自动化分析。解决传统人工复盘效率低、情感分析粒度粗、问题归因片面、舆情反馈滞后等痛点，轻量化落地AI智能分析业务，适配电商运营复盘、产品迭代优化等场景。
技术栈：Python、FastAPI、LangGraph、RAG、Milvus向量数据库、LLM Function Calling、ABSA细粒度情感分析、Docker
1.轻量化LangGraph智能体架构设计，实现任务自动化流转 基于LangGraph搭建轻量化智能体协作框架，按照业务流程拆分模块化任务单元，实现数据处理、智能分析、预警推送、报表生成的有序流转，配置基础失败重试机制，替代传统线性脚本执行方式，提升系统模块化程度与运行稳定性，结构清晰易维护。 
2. 基于Function Calling封装工具集，精准清洗有效评价数据 依托LLM函数调用能力，封装专属数据处理工具，实现电商评价增量采集，自动过滤刷单灌水、重复评论、恶意差评等无效噪声数据；支持OCR解析晒图评价文本，统一Valid Reviews有效评价筛选标准，全方位保障底层分析数据质量。 
3. 落地ABSA细粒度情感分析，实现多维度观点拆解 摒弃传统粗粒度整体情感判别，落地ABSA属性级情感分析技术，精准抽取商品质量、物流、包装、尺码、客服等细分维度的正负向用户观点，自动统计差评高频问题与核心痛点，实现用户口碑精细化拆解与精准归因。
4. 构建Milvus向量RAG知识库，辅助业务迭代归因 将历史评价数据、品类痛点、优化方案进行向量化处理，存入Milvus向量数据库搭建专属RAG知识库；针对新增评价，通过相似度检索匹配历史同类问题，辅助完成痛点溯源与原因分析，输出更贴合业务的产品优化建议。 
5. 接口开发与容器化部署，完成业务闭环 基于FastAPI开发标准化后端接口，对接前端可视化看板，实现情感分布统计、问题TOP排行、SKU维度对比等数据可视化展示；通过Docker完成项目容器化打包部署，统一运行环境，实现开箱即用，完成从数据处理到业务展示的完整闭环。
